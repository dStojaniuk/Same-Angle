# Same Angle redesign

In **Restyle room**, finish the prompt and approve the edit and protected regions. Use **Download Codex plan** and **Download prepared photo**. Pass both files to the skill with a new private output directory outside Git. For hand-authored plans, use the matching oriented source photo and its dimensions.

From this worktree, invoke Codex CLI while signed in through ChatGPT.

```sh
env -u OPENAI_API_KEY codex exec --sandbox workspace-write --add-dir /path/to/private-runs \
  '$same-angle-redesign photo="/path/to/downloads/room-prepared.png" plan="/path/to/downloads/room-style-plan.json" output="/path/to/private-runs/wallpaper"'
```

1. From `backend/`, run `uv run --locked --no-sync python -B -m examples.room_redesign prepare PHOTO PLAN OUTPUT`. If preparation rejects a downloaded plan and photo, use the two matching downloads before generating. Read `OUTPUT/plan.json` for the image-edit prompt. Load `before.png` and `guide.png` with `view_image`. The unmarked photo is the edit target. Yellow in the guide indicates where changes are allowed.
2. Call the built-in `image_gen` once. Apply the plan prompt in the yellow areas, with the original framing, aspect ratio, perspective, and architectural lines. Ask for realistic materials, clean joins, and a full-frame photograph free of guide markings. If the built-in tool is unavailable, stop and report that. Use the signed-in Codex session for generation.
3. Copy the native output reported by the tool to `OUTPUT/candidate.png`. From `backend/`, run `uv run --locked --no-sync python -B -m examples.room_redesign finish OUTPUT`. A successful run yields `after.png`, `before-after.png`, and `pixel-checks.json`. Keep the candidate if finishing fails. Rerun `finish` after resolving a write error. Keep `before.png`, `plan.json`, and `prepared-inputs.json` together as generated by `prepare`.
4. Open the comparison. Inspect the requested boundaries on the original-size `before.png` and `after.png`, using local crops if needed. Report any shifted or duplicated edge where the edit meets the original. Report the exact changed-pixel count outside the mask and link the comparison, PNG, and report.

Use a separate output directory for another generation. Each invocation generates one candidate.
